# 项目进展与后续计划

更新：2026-11-27。

## 定位与背景

DesignSpark 面向设计学生、设计师的前期研究，将分散的获奖案例整理为可查找、可回看的本地资料。长期流程是：描述问题 → 本地检索 → 按需采集 → 案例比较 → 设计机制迁移与验证。

## 已完成

1. 红点概念设计奖与 iF 学生奖采集脚本，统一 main 入口；近三年参数、筛选、图片下载、分页检查和错误记录。
2. 红点实时完整类别目录、类别名称解析和索引；归档按年份/大类/细类组织，作品名称保留大小写并带奖项后缀。
3. Markdown 卡片、结构化字段、本地图片链接、增量图片复用与缺漏补采；笔记保护、索引重建与身份去重。
4. 黑白本地网页：分类树、卡片网格、关键词搜索、年份/来源/奖项过滤、详情、图片切换与连续浏览，兼容旧资料。
5. 来源与奖项联动，IF 只显示两种奖项、RedDot 显示红点奖项，切换时清除不适用选项；未知信息不猜测。
6. Windows 后台启动器、应用图标和当前电脑的桌面快捷方式，复用已运行服务、防止重复启动。
7. 初步 PRD、离线测试及真实作品网页预览。作品库数量随本机资料变化，不作为代码版本指标。

## 版本脉络

- 1.0.0：采集脚本初始存档。
- 1.0.1：iF 筛选采集试验。
- 后续本地迭代：统一卡片和增量归档、类别索引、目录命名、本地网页、黑白主题、桌面入口和筛选联动。本次汇总入库，不额外创建正式版本标签。

## 限制与验证边界

- 尚未逐年、逐奖项完成线上覆盖验收；iF 单年依赖官网独立年份选项。
- iF 类别在详情读取后筛选，较慢；旧数据可能缺少奖项。
- 红点奖项在列表取得后精确匹配，服务端参数尚未验证。
- 描述来自 meta description，可能不含完整正文。
- 重跑复用图片不等于网络分页断点续传；新旧资料不自动整体迁移。
- 网页只读；个人作品专门导入、深度卡片分析、自动翻译、语义搜索与 Agent 尚未实现。

## 下一步

1. 卡片设计：人群、情境、设计问题、核心机制、取舍与迁移边界，区分事实、模型分析和笔记。
2. 数据质量：各年份与奖项抽查，分页回归、缺失信息标注和来源追溯。
3. 检索与类别映射：从自然语言提取设计问题，按轻量索引读取相关卡片。
4. 设计启发 Agent：案例比较、机制抽象、适配方向和可验证假设。
5. Skill 封装：脚本、流程和模板与作品库分离；公开数据集需独立核实再分发权限。
